# 📚 Book Vibe

A modern and responsive **book discovery web application** built with **Next.js, React, TypeScript, Tailwind CSS, and DaisyUI**.

Book Vibe provides a clean interface for exploring books and presenting book-related information in a user-friendly way.

## 🌐 Live Demo

🔗 **[View Live Website](https://book-vibe-gamma-three.vercel.app/)**

## 📸 Overview

Book Vibe is designed as a modern book-focused web application with:

* 📚 Book collection interface
* 🔎 Book browsing experience
* 📖 Book information and details
* ⭐ Rating display
* 🏷️ Category and tag information
* 📱 Responsive design
* 🎨 Modern UI components

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Fahad-oni/book-vibe.git
```

### 2. Navigate to the project

```bash
cd book-vibe
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 📦 Build for Production

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
